TYRE SALES AND REPAIR — SAULSVILLE

A standalone, mobile-first business website built with vanilla HTML, CSS and JavaScript.

To view: open index.html in a modern web browser.

Included files:
- index.html: page content, metadata and contact links
- styles.css: responsive styling
- script.js: updates the copyright year
- saulsville-tyre-service.jpg: generated workshop image

Contact links are wired to the supplied business phone number, WhatsApp number and Google Maps directions search. Opening hours and prices are intentionally not listed because they were not provided.
